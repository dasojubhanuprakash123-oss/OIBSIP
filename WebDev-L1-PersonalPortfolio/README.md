# Personal Portfolio — Bhanu Prakash Dasoju

A responsive personal portfolio website created for the Oasis Infobyte Internship Program, Web Development and Designing Track, Level 1 — Task 2.

## Features

- Profile/hero section with name, role and avatar placeholder
- About Me section
- Technical skills grid
- Two project cards
- Contact section with email, GitHub and LinkedIn links
- Smooth-scroll navigation
- Responsive desktop and mobile layouts
- Keyboard focus styles and reduced-motion support

## Technologies Used

- HTML5
- CSS3
- CSS Grid and Flexbox
- Responsive media queries

## Project Structure

- `index.html` — page content and structure
- `style.css` — design, layout and responsive styles
- `screenshots/` — add screenshots of the finished website here

## How to Run

1. Open this folder in your code editor.
2. Open `index.html` in a browser, or use a local development server.
3. Resize the browser to check the mobile layout.

## Before Submitting

- Replace the placeholder email in the Contact section with your preferred public contact email.
- Replace the GitHub and LinkedIn placeholder URLs with your own profile links.
- Replace the project GitHub placeholder links with the actual project URLs.
- Add screenshots to the `screenshots/` folder.
- Verify all links and test the site on desktop and mobile.
