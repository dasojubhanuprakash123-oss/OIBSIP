# A Life That Inspired — A. P. J. Abdul Kalam

A responsive tribute page created with HTML, CSS, and vanilla JavaScript for the Oasis Infobyte (OIBSIP) Web Development and Designing Internship — Level 2, Task 2.

## Highlights
- Editorial layout with warm paper tones and forest-green accents
- Responsive design for desktop, tablet, and mobile
- Tribute introduction, inspirational quote, biography, timeline, and legacy section
- Inline SVG illustration; no image asset required
- Navigation links to page sections with active-section highlighting
- Semantic HTML and reduced-motion support

## Run locally
1. Open `index.html` in a browser, or open the folder in VS Code.
2. Optionally use the VS Code **Live Server** extension.
3. No package installation or build step is required.

Google Fonts load when online; fallback fonts are included.

## Review checklist
- Click **His story**, **Milestones**, and **Legacy**.
- Check each navigation link scrolls to its section.
- Resize the browser to check mobile layout.
- Test keyboard navigation with Tab and Enter.
