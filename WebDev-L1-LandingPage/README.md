# NovaTech Landing Page

## Project Overview
NovaTech is a responsive landing page created as part of the Oasis Infobyte Internship Program (OIBSIP), Web Development and Designing Track, Level 1 – Task 1.

The website represents a fictional technology brand focused on innovation, modern design, and smart solutions.

## Features
- Responsive navigation bar
- Hero section with a call-to-action button
- Features section with three feature cards
- About section
- Contact section
- Footer with navigation links
- Responsive layout for smaller screens

## Technologies Used
- HTML5
- CSS3
- Flexbox and CSS Grid
- Responsive web design using media queries

## Project Structure
- `index.html` — Website structure and content
- `style.css` — Styling and responsive layout
- `README.md` — Project documentation

## How to Run
1. Download or clone this repository.
2. Open the `WebDev-L1-LandingPage` folder.
3. Open `index.html` in a web browser.
